# Archive — completed handoff notes

Each is a builder's account of a finished piece of work: what changed, how it
was verified, what was left undone. **Historical, not current.** Read one only
when you are about to touch the area it describes and want to know why it looks
the way it does.

Live documents live one directory up. The reason these are down here is that ten
of them, ~1,500 lines, buried the four documents an agent actually needs.
